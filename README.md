# AleHanndro Neovim config

## Requirements

Before installing, make sure you have the following:

- Neovim $\ge 0.11.0$
- A **Nerd Font** installed (e.g. FiraCode, JetBrainsMono, CommitMono)
- `git`, `make`, `npm`, `python`, and `curl` or `wget`

## Installation

```bash
# Backup old config (if any and only if you want)
mv ~/.config/nvim ~/.config/nvim.bak

# Clone the repository
git clone https://codeberg.org/AleHanndro/nvim.git ~/.config/nvim --depth=1
```
